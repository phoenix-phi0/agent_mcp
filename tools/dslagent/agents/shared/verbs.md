## 可用动词
白名单：别的动词和语句一律判错。

### code 包
只能读写项目里的文件；不能改测试文件。

#### 读
- 列文件 [全部] → 文本：所有 .py 文件和行数；写「全部」另列 .json / .csv / .md 等
- 搜索代码 正则 [范围] → 文本，每行「文件:行号: 那一行」
  - 正则里空格写 \s
  - 范围：文件或目录（相对项目根），多个用逗号隔开、不要空格；不写就搜全部 .py
  - 例：设 hits = 搜索代码 def\s+is_valid tools/dsl.py　设 hits = 搜索代码 KEYWORDS tools/dsl_core.py,tools/dslagent
  - 命中超过 30 条：只返回总数、每个文件的命中数和前 30 条；换更具体的标识符再搜，或直接读整个文件
- 读片段 段落 → 文本，带行号前缀「  12| 」
  - 段落写「文件:起-止」，多段用逗号隔开、不要空格；每段 ≤ 200 行
  - 只写文件名 = 读整个文件：≤ 500 行整份返回；更长的只给前 120 行 + 函数 / 类及行号清单
  - 没写文件名的段沿用前一段的文件：pkg/a.py:1-20,80-95 = a.py 的两段
  - 例：设 src = 读片段 pkg/coupon.py,tests/test_coupon.py:1-40
- 查引用 名字 [py] → {n, files, refs:[{file, line, text}], text}
  - 整词匹配；写 py 只看 .py

#### 运行
- 运行代码 {code} → {ran: 是/否, text}
  - code：≤ 30 行 Python，只能来自变量；在项目根目录跑，只用于 import 项目模块、print 中间值
  - 10 秒超时；不联网；不写文件；不能 import subprocess / socket / shutil、用 os.system、跑测试
  - 违反被拒（ran=否，text 是原因）；让模型写 code 时把限制写进提示词
  - code 单行时：设 code = t=0;import time;print(1)（整段不含空格，或用 ; 连接，不要写成「import os, json」这样词+空格开头）
- 跑测试 → {passed: 是/否, summary}
  - summary：失败摘要（测试名、调用位置、异常行），或「全部通过：…」

#### 写
- 改文件 {e} → {ok: 是/否, msg, n}
  - e：{file, old, new} 或 {edits:[{file, old, new}, …]}；old 一字不差（含缩进，不带行号前缀），在文件里只出现一次；new 是替换后的文本
  - old 为空且文件不存在 = 新建，new 是完整内容；任何一处对不上就整体不改，msg 说明哪处错
  - 原文已经看到：写进 #改法 段，设 res = 改文件 {e1}；没看到：用 派任务（见下）
- 写文件 {e} → {ok: 是/否, msg, n}
  - e：{file, content} 或 {files:[{file, content}, …]}
  - 新建文件或整份覆盖已有文件；任何类型（.py / .json / .md…）；父目录自动建
  - 不许写测试文件
  - 内容由模型产出时用 问JSON … 格式 files:列表 note:文本，提示词里写明「每项字段名固定为 file（相对路径）、content（完整内容）」
  - 改局部优先用 改文件；新建或整份重写才用 写文件
- 删文件 路径 → {ok: 是/否, msg}
  - 删项目里的一个非测试文件；不存在也算成功
- 改模块名 旧路径 新路径 兼容 导出名 → {ok: 是/否, msg, left}
  - 把模块 旧路径(.py) 挪到 新路径，范围内非测试 .py 的 import 和「模块名.函数」调用按词边界全换成新模块名
  - 兼容=是：旧路径留兼容模块，只从新模块重新导出 导出名（逗号分隔；空 = 全部公开名字）
  - 例：设 m = 改模块名 pkg/a.py pkg/b.py 是 f,g

#### 安全约束
执行前自动检查，会被拦（ok=否，msg 说明原因）：删仍被引用的文件、删源数据而新数据未生成、覆盖任务没点名的数据文件、动 tests/、越出项目。

### text 包
- 匹配 文本 正则 → {matched: 是/否, all, groups}；找全部 文本 正则 → 列表；替换 文本 正则 [替换为] → 文本；截取 文本 起 [长度]
- 相等 甲 乙 → 是/否；挑行 文本 正则 → {hits, rest}；按正则切分 文本 正则 → 列表

### common 包
- 解析JSON 文本 → 结构；解析不了给空字典
- 列表长度 甲,乙 或 列表长度 {列表变量} → 数
- 转数字 文本
- 取字段 JSON文本 路径
- 当前时间 [日期|时间戳] → 本地时间文本 YYYY-MM-DD HH:MM:SS；日期 → YYYY-MM-DD；时间戳 → 整数秒
- 派任务 任务 [入参] [逻辑] [格式] → {结果, 状态, 原因}
  - 把一件子任务交给模型，算 1–2 次模型调用；四个参数都先 设 进变量再传（格式可直接写在行末）
  - 入参：对象 {名: 值}；值写「文件:起-止」时，动词读出那几行附上
  - 格式：结果 的字段，字段:类型 逗号隔开（同 问JSON）；状态只能是 成功|失败|超出预期
  - 回复不合格重答 1 次；仍不合格返回 状态=失败、原因=格式不合格
  - 例：设 inp.src = pkg/calc.py:1-40 / 设 r = 派任务 {desc} {inp} {logic} edits:列表,note:文本 / 如果 {r.状态} 等于 成功 … 用 {r.结果.edits}
- 并行派任务 {jobs} [并发] → 列表（顺序同 jobs），每项 {结果, 状态, 原因}
  - jobs 每项是 {任务, 入参, 逻辑, 格式}，用 列表加项 拼
  - 只并行互不依赖的子任务；并发缺省 3
