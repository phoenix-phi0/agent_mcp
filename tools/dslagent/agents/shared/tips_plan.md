## 写法要点
- 一条语句只能写在一行
  - 问 / 问JSON 的提示词里不能换行：换行后的半句会被当成新语句判错
  - 需要分段用「；」或「|」隔开
  - 「格式 …」也写在同一行末尾
- 赋值右边不要以「词+空格」开头
  - 错：设 h = 根因 在 catalog 里 —— 会把「根因」当成动词调用，报「没有名为…的动词」
  - 对：整段不含空格，或第一个空格前带「：」或 {变量}
  - 例：设 h = 线索：根因在 catalog 里
  - 例：设 h = {d.reason} 待核实
- 修改内容的字段名固定为 {file, old, new}；edits 是这种对象的列表
  - 问JSON 要 edits 时，提示词里写明「每项字段名固定为 file（相对路径）、old、new」
  - 不写的话模型常给 path，或不给文件名，改文件会失败
- 问JSON / 派任务 调的模型看不到代码
  - 它每次调用都是全新的，不记得前面的调用
  - 要它看的内容先用动词读出来，嵌进提示词（派任务 可用入参「文件:起-止」）
