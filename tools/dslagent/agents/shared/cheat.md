## DSL 速查
只能用这里列出的语句。

### 基本规则
- 一行一句；语句本身不能换行（{变量} 的值可以是多行）
- # 开头是注释
- 第一行必须是：用包 common text code
- 动词参数按空格切：带空格的文本先 设 进变量，再用 {变量} 传
- 提示词里可以直接嵌 {变量}
- 不要写模型调用的「用 …」后缀，也不要写「模型」语句

### 变量
- {task}：预置变量，任务描述
- {name}：变量；{r.action}：取字段
- {x 或 默认}：取不到用默认
- {x 或}：取不到给空

### 赋值
- 设 name = 值：文本赋值；右边整个是 {var} 时保留结构（字典 / 列表）
- 设 name = 动词 参数…：调动词，返回值存进 name；是结构时用 {name.字段} 取
- 设 n = 计算 {a} + 1：算术（+ - * / // % 和括号；函数 取整 四舍五入 最大 最小 绝对值）。加法、百分比都用 计算，不用旧写法 相加 / 算比例（百分比：计算 四舍五入({对} * 100 / {总})）
- 设 t = 当前时间 [日期|时间戳]：取当前本地时间（common 包）

### 调模型
- 问 reply = 提示词：拿一段文本
- 问JSON r = 提示词 格式 字段:类型 … [重问 N 次]：拿 JSON
  - 类型：文本、数字、是否、列表、A|B|C（枚举）；字段名后加 ? 表示可选
  - 格式不对自动带着问题重问（默认 2 次），用完报错停脚本
  - 例：问JSON v = 看测试结果：{t.summary} 格式 action:改|查|停 reason:文本 code?:文本

### 打印
- 打印 文本：输出一行

### 条件
- 写法：如果 条件 … 否则如果 条件 … 否则 … 结束
- 条件：甲 运算符 乙
- 运算符：等于 不等于 包含 不包含 为空 不为空 大于 小于 不小于 不大于 开头是 结尾是（中文是规范写法；符号 > < >= <= == != 也可用，语义相同；单个 = 不是运算符）
- 组合：且 / 或 / 非 / 括号

### 循环
- 遍历 i 于 1，2，3 … 结束：按列表逐项循环（全角逗号分隔）
- 当 条件 最多 N 次 … 结束：条件成立就再跑一轮
  - 每轮开头重新判断，必须写「最多 N 次」（N ≤ 1000）；跑满仍成立就接着往下走，{loop_full} 为 是
- 重复 N 次 [计数 i] … 结束：固定次数循环，i 从 1 开始
- 跳出 / 继续：结束 / 跳过最内层循环的本轮（只能写在 当、重复、遍历 里）

### 子脚本
- 执行 _plan/名字.zs key={var}（独立作用域，key 在子脚本里是 {key}）；设 x = 执行 … 拿子脚本 返回 的值
- 返回 值：结束当前脚本（在子脚本里只结束子脚本）

### 业务层（services/<模块>.zs，一个文件一个模块、多个具名函数）
- 文件：`业务 模块名`（= 文件名）… `结束`；里面 `依赖 其他模块`（不写就不能调）、`用包 db`、`[公开] 函数 名 入参 可选入参? …` … `结束`
- 函数是独立作用域，只有入参（`?` 结尾可选，不传是空串）；不写「公开」只给本模块用
- 调用：`设 r = 调用 模块.函数 键=值`（同模块可只写函数名）；只能调公开函数、跨模块要在 依赖 里、必填必须给、不认识的键报错；`执行 x.zs` 仍是跑脚本
- 返回：`返回 值`；业务错误：`报错 404 文字`（4xx 码，沿调用链到接口自动成 HTTP {"error": 文字} + 码）；接住：`设 r = 调用 … 出错时 e`（{e.code} {e.error}，没出错 {e} 是空串）
- 事务：外层 `事务` 里调的函数写库并入同一事务；函数里自己的 `事务` 并入外层

### 结束与预算
- 终止 成功|失败|超出预期 原因：结束整个流程（循环、如果里都能用；在子脚本里只结束子脚本）
  - 调用方 设 r = 执行 _plan/x.zs 后可用 {r.状态} {r.原因} {r.停在}
- 预算 调用 N 秒 M：整个流程最多调 N 次模型、跑 M 秒；N 含 派任务 / 并行派任务、子脚本、重问；N、M 都是正整数，N 不能是 0
  - 超出按 终止 超出预期 结束。写在开头，例：预算 调用 6 秒 300

### #改法 段（写在脚本末尾）
多行代码原文不写进语句，写进段里，按字面、不转义。段里只能有下面的块；脚本里 {名} 就是这份改法，用 设 res = 改文件 {名} 一次套全部条目。

    #改法 e1
    @@ 改 pkg/calc.py
    <<<<<<< 原文
    …原文…
    =======
    …新文…
    >>>>>>> 新文
    @@ 新建 pkg/util.py
    <<<<<<< 内容
    …新文件的完整内容（文件已存在就不写）…
    >>>>>>> 新文

- 原文一字不差（含缩进，不带「  12| 」行号前缀），在文件里只能出现一次；0 次或多次 → ok=否，msg 报次数，整体不改
- 同一个 @@ 改 下可连写多对 <<<<<<< / ======= / >>>>>>>；可以有多段 e1、e2…
- 所有 #改法 段都放在脚本最后，段后面不能再写脚本语句

### #清单 段（写在 #改法 段之后）
- 逐行写：改 路径:函数名 / 新建 路径 / 删 路径，列出这次要动的全部文件；可加一行「提示 …」
