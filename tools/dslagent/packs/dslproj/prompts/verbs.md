## 可用动词
白名单：别的动词和语句一律判错。
参数写法：<名> 必填，<名?> 可选，<名=默认> 有默认值；调用时除位置参数外可写 键=值。

### code 包（读、搜、改、写文件；只能动本次范围内的路径，别的路径写 / 删会被拦下）
- 列文件 [全部] → 文本；搜索代码 正则 [范围] → 每行「文件:行号: 那一行」（默认只搜 .py，搜 DSL 文件要把范围写成目录或文件，如 services/,routes/）
- 读片段 段落 → 带行号的文本；段落写「文件:起-止」，多段用逗号隔开、不要空格；只写文件名 = 读整个文件（≤ 500 行整份）；文件名里可写 * 通配（queries/graph_*.sql、routes/graph*.zs 读到全部匹配的文件）
- 改文件 {e} → {ok: 是/否, msg, n}：e 是 #改法 段里的 {名}（JSON 列表 [{file, old, new, line?}, …]），或 {file, old, new} / {edits:[…]}；old 一字不差（含缩进，不带行号前缀）；恰好出现 1 次就用它，多处按 line（old 开头所在行）选最近的一处，没给 line 或并列就报错；任何一条出错整体不改，msg 逐条写第几条、文件、原因
  - 新建文件：old 写空串，new 是完整内容（文件已存在报错，已存在的用原文当 old）
- 写文件 {e} → {ok, msg, n}：e 是 {file, content} 或 {files:[{file, content}, …]}，新建或整份覆盖，父目录自动建
- 删文件 路径 → {ok, msg}
- 不能写 tests/ 下的文件（验收用例由程序按约定跑）；contracts/、别的模块的文件不在范围内

### dslproj 包（检查，都不改文件）
- 加载检查 模块 → {ok: 是/否, problems, count}：服务启动时「接口出错」那类问题现在就查（条件看不懂、变量名非法、业务函数调用不对……），只报该模块的 services / routes 文件
- 比对约定 模块 → {consistent: 是/否, diffs, count}：实际函数头（名字 / 公开 / 入参顺序与可选）、依赖、接口、表（entities 里的实体）与约定是否一致
- 跑用例 模块 → {all_passed: 是/否, failures, total}：约定里的验收用例，每个在空库上单独跑（按本模块和上游模块的 entities 建表），时间固定；失败是文本，每个失败用例一行

### text 包
- 匹配 文本 正则 → {matched: 是/否, all, groups}；找全部 文本 正则 → 列表；替换 文本 正则 [替换为] → 文本；截取 文本 起 [长度]
- 相等 甲 乙 → 是/否；挑行 文本 正则 → {hits, rest}；按正则切分 文本 正则 → 列表

### auth 包（注册、登录、退出；配合路由顶层 `认证 …` 用，要先 用包 auth http）
- 注册用户 库 语句名 {request} → 用户名或 [出错]…；登录 库 语句名 {request} → 用户名或空串（失败不区分没这个人/密码错，同一用户名连续失败 5 次锁 5 分钟）
- 建用户 / 重置密码 / 改密码（管理员建号、重置、自己改密码，同样收整个 {request}）；退出登录 → "ok"（删登录 cookie）
- 业务层原语（自己的登录 / 建号流程不想走整段收 {request} 的现成动词时用）：
  哈希密码 明文 → 哈希串；核对密码 明文 哈希 → 是/否；登录被锁 用户名 → 是/否；记登录失败 用户名 → ok；
  清登录失败 用户名 → ok（连续失败 5 次锁 5 分钟，和上面几个整段动词共用同一套限流计数）；签发登录 用户名 → ok（让路由器发登录 cookie）

### doc 包（从上传的文档取纯文本，要先 用包 doc）
- 读文档 路径 → {kind, text, pages, paragraphs, chars, error}：按扩展名读 pdf/docx/md/txt；读不了（扫描版、密码、坏了）error 是一句人话给用户看，不抛错

### common 包
- 解析JSON 文本 → 结构；列表长度 列表 → 数；转数字 文本；取字段 JSON文本 路径；当前时间 [日期|时间戳]
- 归一化 / 列表加项 {列表} {项}：见 DSL 速查
- 派任务 任务 [入参] [逻辑] [格式] → {result, status, reason}
  - 把一件子任务交给模型，算 1–2 次模型调用；四个参数都先 设 进变量再传（格式可直接写在行末）
  - 入参：对象 {名: 值}；值写「文件:起-止」时，动词读出那几行附上
  - 格式：result 的字段，字段:类型 逗号隔开；status 只能是 成功|失败|超出预期
  - 例：设 r = 派任务 {desc} {inp} {logic} edits:列表,note:文本；用 {r.result.edits}
- 并行派任务 {jobs} [并发] → 列表，每项 {result, status, reason}
