### #改法 段（写在脚本末尾）
改动不写进语句，写进脚本末尾的 #改法 段：段里直接写一个 JSON 列表（可多行，按 JSON 的字符串转义：换行写 \n、引号写 \"），脚本里 {名} 就是这份改法，用 设 res = 改文件 {名} 一次套全部条目。段里的内容原样交给 改文件，不展开 {变量}（DSL 代码里的 {p} 就是字面文本）。

    #改法 e1
    [
      {"file": "services/graph.zs", "old": "…原文…", "new": "…新文…"},
      {"file": "queries/graph_x.sql", "old": "", "new": "…新文件的完整内容…"}
    ]

- 每条 {file, old, new, line?}：file 是相对项目根的路径；old 是原文，一字不差（含缩进，不带「  12| 」行号前缀）；new 是替换后的文本
- old 写空串 = 新建文件（文件已存在就报错）；整份重写已有文件：一条 edit，old 取整个原文
- old 在文件里恰好出现 1 次就直接用它；可能出现多次（如多个函数里都有的 `返回 {p}`）就多带上下文行，或加 line = old 开头所在的行号（读片段 给的行号，1 起）：多处时选起点离 line 最近的一处，并列报错
- 同一文件的多条按先后顺序套，后一条对着前一条改完的文本找 old；任何一条出错整体不改，msg 逐条写第几条、哪个文件、什么原因
- 段只能有这一个 JSON，放在脚本最后，段后面不能再写脚本语句；可以有多段 e1、e2…
