# 给模型调用挂载文件

    问 讲解 = 用中文解释这一课的重点 附 content/n2n3/doushi_01.md

    问 对比 = 比较这两课的难度 附 content/a.md,content/b.md

    对话 回复 = 按这份人设回答 附 prompts/teacher.md

现在要挂文件得先 `读取` 再拼 `{变量}`，两行而且提示词里塞满了插值。
这个后缀把它压成一句。

## 一、解析

跟「重试」一样是后缀，加在 `问 / 流式 / 对话` 的末尾。

顶部加正则：

```python
# 挂载文件：问 甲 = 提示词 附 a.md,b.md
ATTACH_RE = re.compile(r"\s+附\s+(\S+)$")
```

文件名不能有空格——跟动词参数、条件值一样的限制。多个文件用逗号分隔。

关键字表里**不加**「附」：它不是独立语句，只在这三条语句的尾巴上出现。
加进 KEYWORDS 会让「附录 xxx」这种普通文本行被当成语句。

## 二、剥后缀的辅助函数

放在 `_do_ask` 前面：

```python
    def _split_attach(self, rest: str) -> tuple[str, list[str]]:
        """把「… 附 a.md,b.md」的后缀剥下来，返回 (剩余部分, 文件列表)。"""
        m = ATTACH_RE.search(rest)
        if not m:
            return rest, []
        files = [x.strip() for x in re.split(r"[,，]", m.group(1)) if x.strip()]
        return rest[:m.start()], files

    def _attach(self, prompt: str, files: list[str]) -> str:
        """把文件内容拼到提示词前面。

        文件在前、指令在后：长上下文里，指令放最后模型更容易照做。
        反过来的话，几千字的课文会把前面那句要求冲淡。

        文件读不到直接报错，不静默跳过——挂载失败而照样发请求的话，
        模型会基于空上下文编一个答案出来，看着像正常回复，
        比报错难查得多。
        """
        if not files:
            return prompt
        blocks = []
        for name in files:
            path = self._safe_path(self.expand(name))
            if not path.is_file():
                raise DSLError(f"挂载的文件不存在：{self._rel(path)}")
            body = path.read_text(encoding="utf-8")
            blocks.append(f"── {self._rel(path)} ──\n{body}")
        return "\n\n".join(blocks) + "\n\n" + prompt
```

## 三、三条语句接上

`_do_ask` 里，剥重试之后、拆赋值之前：

```python
    def _do_ask(self, rest: str, lineno: int) -> None:
        retry, cond = 0, None
        m = RETRY_RE.search(rest)
        if m:
            retry, cond = int(m.group(1)), m.group(2).strip()
            rest = rest[:m.start()]

        # 挂载后缀在重试之后剥：写「附 a.md 重试 3 次 直到 …」时，
        # 重试在更外层，先剥掉它剩下的才是「… 附 a.md」
        rest, files = self._split_attach(rest)

        name, prompt = self._split_assign(rest, "问")
        prompt = self._attach(self.expand(prompt), files)
        ...
```

**`对话` 有个坑**：挂载的内容会进历史，之后每轮都重发。一份 6700 字的
课文挂一次，后面十轮都带着它。要么挂完就 `修剪历史`，要么用 `问`
——那个不进历史。这条写进语法说明里。

## 四、`系统` 也支持

```python
        elif head == "system":
            rest, files = self._split_attach(rest)
            self.system = self._attach(self.expand(rest), files)
```

这样人设可以写在 md 里：

```
系统 你是日语教师，遵循下面的原则 附 prompts/teacher.md
```

## 五、文档更新

`dsl.py` 的模块 docstring 里，语句表加一行说明：

```
挂载文件：

    问 / 流式 / 对话 / 系统 的末尾可以加「附 文件名」，多个用逗号分隔。
    文件内容拼在提示词前面，指令在后——长上下文里指令放最后模型更
    容易照做。

        问 讲解 = 解释这一课 附 content/n2n3/doushi_01.md
        问 对比 = 比较难度 附 content/a.md,content/b.md

    文件名不能有空格。读不到直接报错，不静默跳过。

    「对话」挂的内容会进历史，之后每轮重发——大文件配合「对话」要
    留意 token，通常挂完就该「修剪历史」，或者改用「问」。
```

## 不做的

**不做分段挂载**（挂某个文件的某几行）。那要引入行号或标记语法，而且
真需要的话说明文件该拆小了。

**不自动压缩**。几千字的文件挂上去就是几千字的 token，引擎不替人做
截断——悄悄砍掉一半内容比明确的 token 消耗更糟。
