# 让动词能返回结构

改两处，都在 `tools/dsl.py`。改完动词就能跟 `读JSON` 语句一样产出对象和
列表，不必把什么都压成字符串。

## 一、`_do_verb` 里不要无脑 str()

现在是：

```python
        if kind == "python":
            result = impl(**params)
            result = "" if result is None else str(result)
```

改成：

```python
        if kind == "python":
            result = impl(**params)
            # 结构原样留着——str() 一个 dict 会得到 Python 的字面量
            # （单引号、True 而不是 true），拿去 json.loads 都解析不了。
            # 别的类型（Path、自定义对象之类）仍然转字符串兜底。
            if result is None:
                result = ""
            elif not isinstance(result, (str, dict, list, int, float, bool)):
                result = str(result)
```

脚本动词那支不用改：`sub.run()` 本来就返回字符串。

## 二、`_deliver` 要区分「存变量」和「输出」

现在是：

```python
    def _deliver(self, result: str, assign_to: str | None) -> None:
        self._last_result = result
        if assign_to:
            self.vars[assign_to] = result
        elif result:
            for line in result.splitlines():
                self._emit(line)
```

改成：

```python
    def _deliver(self, result, assign_to: str | None) -> None:
        """把子调用的结果存进变量，或逐行输出。

        存变量时保留原始类型——动词返回的列表要还能拿去遍历。
        输出时才转文本，因为 output 是字符串列表。
        """
        text = to_text(result)
        self._last_result = text
        if assign_to:
            self.vars[assign_to] = result
        elif text:
            for line in text.splitlines():
                self._emit(line)
```

关键是 `self.vars[assign_to] = result` 而不是 `text`——存的是原始值，
`设 题号表 = 挑题号 ...` 之后 `{题号表}` 仍是列表，能直接遍历。

`_last_result` 存文本：它只被「逐项」块的自动输出用，那里要的就是文本。

## 改完能写什么

```
设 题号表 = 挑题号 content/n2n3/题库 3 doushi_01
遍历 题号 于 {题号表}
  设 题 = 取题 content/n2n3/题库 {题号}
  打印 {题}
结束
```

前提是 `挑题号` 改成 `return [q.get("id", "") for q in picked]`。

## 顺带要改的动词

这些现在为了「能被循环吃」而返回逗号串，可以改成返回列表：

| 动词 | 现在 | 改成 |
|---|---|---|
| `挑题号` | `",".join(ids)` | `list(ids)` |
| `错题号` | `",".join(wrong)` | `list(wrong)` |
| `列考点` | `"，".join(f"{k}（{v}题）")` | 保持——那是给人看的展示文本 |

**不要全改**。`列课程`、`列考点` 的输出是给学习者看的，返回列表反而要
调用方自己拼。判据是「这个结果主要给人看还是给循环吃」。

改了之后调用方也要跟着改：`app2/serve.py` 里 `call_verb("挑题号", ...)`
拿到的会是列表，`if not 题号 or 题号.startswith("[")` 这类判断要改成
`if not 题号`。

## 不改的地方

`Registry.call`（`agents/registry.py`）是 agent 工具的返回值处理，跟动词
是两回事，不受影响。agent 工具的结果要塞进 messages，必须是字符串。
