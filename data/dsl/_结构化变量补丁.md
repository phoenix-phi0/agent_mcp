# DSL 结构化变量：改动清单

让变量能存对象和列表，而不只是字符串。

原型验证过 9 项插值、3 种遍历、条件比较、文件写入，全通过。
改动集中在三个函数加两条语句，`expand` 的旧行为一字不变。

## 一、新增两个模块级函数

放在 `split_items` 后面。

```python
def to_text(value) -> str:
    """结构化值转文本。插值、写文件、条件比较都走这里——
    统一一处转换，免得三处各写各的、行为分岔。

    紧凑 JSON 而不是 indent：插进一行文本里不该炸成多行。
    布尔转成「是/否」而不是 True/False——脚本里写
    「如果 {标志} 等于 是」比写 True 自然。
    """
    if isinstance(value, str):
        return value
    if value is None:
        return ""
    if isinstance(value, bool):
        return "是" if value else "否"
    if isinstance(value, (int, float)):
        return str(value)
    return json.dumps(value, ensure_ascii=False, separators=(",", ":"))


def dig(obj, path: str):
    """按点号路径取值，取不到返回 None。

    纯数字段当数组下标，支持负数：{题目.-1.id} 取最后一题。
    """
    cur = obj
    for key in path.split("."):
        key = key.strip()
        if isinstance(cur, dict) and key in cur:
            cur = cur[key]
        elif isinstance(cur, list) and key.lstrip("-").isdigit():
            i = int(key)
            if not -len(cur) <= i < len(cur):
                return None
            cur = cur[i]
        else:
            return None
    return cur
```

顶部要 `import json`（现在没有）。

## 二、expand 支持点号路径

```python
    def expand(self, text: str) -> str:
        """把 {变量名} 替换成变量值，未定义的原样保留。

        变量是结构化值时按 to_text 转；{名.路径} 深入结构取值。
        取不到仍然原样保留——保留而不是报错，是为了拼写错时看得见，
        这条行为跟以前一样。
        """
        def repl(m):
            expr = m.group(1).strip()
            if expr in self.vars:
                return to_text(self.vars[expr])
            if "." in expr:
                head, _, path = expr.partition(".")
                if head in self.vars:
                    got = dig(self.vars[head], path)
                    if got is not None:
                        return to_text(got)
            return m.group(0)
        return re.sub(r"\{([^{}]+)\}", repl, text)
```

**注意取值顺序**：先查完整变量名，再拆点号。变量名本身含点号时（现在
不允许，但将来可能）不会被误拆。

## 三、循环支持列表

`_exec_block` 里 each/foreach 那段，把

```python
                for item in split_items(items):
```

改成

```python
                for item in iter_items(items):
```

并新增：

```python
def iter_items(value):
    """循环要遍历什么。

    列表直接遍历，每项可以是对象——循环变量拿到的就是那个对象，
    块内用 {项.字段} 取值。
    字典遍历它的键。字符串保持原行为：按逗号拆。
    """
    if isinstance(value, list):
        return value
    if isinstance(value, dict):
        return list(value.keys())
    return split_items(to_text(value))
```

`_parse_each` 现在返回的 `items` 是 `self.expand(...)` 之后的字符串，
这里要改成不展开、直接取变量值：

```python
    def _parse_each(self, rest, lineno):
        """返回 (变量名, 列表值)。列表值可能是字符串也可能是结构。"""
        def resolve(raw):
            raw = raw.strip()
            # 整个就是一个变量引用时，取原始值而不是展开后的文本——
            # 展开了就变成 JSON 字符串，列表身份丢了
            m = re.fullmatch(r"\{([^{}]+)\}", raw)
            if m:
                name = m.group(1).strip()
                if name in self.vars:
                    return self.vars[name]
                if "." in name:
                    head, _, path = name.partition(".")
                    if head in self.vars:
                        got = dig(self.vars[head], path)
                        if got is not None:
                            return got
            return self.expand(raw)

        if "=" in rest:
            name, _, items = rest.partition("=")
            return self._check_name(name.strip(), lineno), resolve(items)
        for word in IN_WORDS:
            m = re.match(rf"^(.+?)\s*{re.escape(word)}\s+(.+)$", rest)
            if m:
                return self._check_name(m.group(1).strip(), lineno), resolve(m.group(2))
        raise DSLError(f"第 {lineno + 1} 行：循环语法应为「遍历 名 于 甲，乙，丙」")
```

这是整个改动里唯一微妙的地方：**`遍历 题 于 {题目}` 必须拿到列表本身，
不能拿展开后的 JSON 文本**，否则列表身份就丢了。

## 四、条件比较

`_eval_condition` 里展开条件用的是 `self.expand(cond)`，自动就走了
`to_text`，不用改。数值比较照常——`{进度.day}` 展开成 `5`，能跟 3 比大小。

`为空` 判断建议补一条：结构为空时也算空。在 `_eval_parts` 的 `empty`
分支前加，或者接受「`[]` 不算空」这个现状（`to_text([])` 是 `"[]"`，
非空字符串）。我倾向补：

```python
        if op == "empty":
            return left.strip() in ("", "[]", "{}")
        if op == "not_empty":
            return left.strip() not in ("", "[]", "{}")
```

## 五、两条新语句

`KEYWORDS` 加：

```python
    "读JSON": "load_json", "载入JSON": "load_json",
    "读JSONL": "load_jsonl", "载入JSONL": "load_jsonl",
```

`_exec_stmt` 加两个分支：

```python
        elif head == "load_json":
            name, fname = self._split_assign(rest, "读JSON")
            path = self._safe_path(self.expand(fname))
            if not path.is_file():
                raise DSLError(f"文件不存在：{self._rel(path)}")
            try:
                self.vars[name] = json.loads(path.read_text(encoding="utf-8"))
            except json.JSONDecodeError as e:
                raise DSLError(f"{self._rel(path)} 不是合法 JSON：{e}") from e

        elif head == "load_jsonl":
            name, fname = self._split_assign(rest, "读JSONL")
            path = self._safe_path(self.expand(fname))
            if not path.is_file():
                raise DSLError(f"文件不存在：{self._rel(path)}")
            rows, bad = [], 0
            for i, line in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
                line = line.strip()
                if not line:
                    continue
                try:
                    rows.append(json.loads(line))
                except json.JSONDecodeError:
                    bad += 1
                    if bad == 1:
                        self._emit(f"[第 {i} 行不是合法 JSON，已跳过]")
            if bad > 1:
                self._emit(f"[共跳过 {bad} 行无法解析的内容]")
            self.vars[name] = rows
```

jsonl 坏行**跳过而不是中断**：573 行的题库里有一行坏了就整个跑不了，
代价太大。但要提示，否则静默丢数据比报错更糟。

## 六、保存与追加

`_split_file_arg` 里 `self.expand(content)` 已经走 to_text，不用改。
`保存 文件 {对象}` 会写出紧凑 JSON——想要缩进格式的话另说。

## 改完能写什么

```
读JSON 进度 = memory/φ-0/progress.json
打印 第{进度.hiragana.current_day}天
如果 {进度.hiragana.current_day} 大于 3
  打印 进度正常
结束

读JSONL 题库 = content/n2n3/题库/doushi_01.jsonl
遍历 题 于 {题库}
  打印 [{题.id}] {题.题干}
结束
```

`挑题号`、`列考点` 那类「为了能被循环吃而返回逗号串」的动词就不必要了——
动词可以直接返回结构，但**动词返回值现在是 str**，要让动词也能返回结构
得改 `Registry.call`（现在非 str 会被 json.dumps 成字符串）。那是下一步，
不在这个补丁里。

## 不做的事

变量不加类型声明、不加字面量语法（`设 表 = [1,2,3]` 仍然是字符串）。
结构只能从文件读进来或由动词产生——这样语言表面几乎不变，学习成本为零。
