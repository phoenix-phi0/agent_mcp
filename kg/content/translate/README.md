# 把英文释义翻成中文

词库里有 7330 条词的释义是英文（来自 JMdict/OpenJLPT，那是日英词典）。
这个目录把它们分成 51 批，每批 150 条，可以交给别的对话翻。

## 给翻译的人（或对话）看的

每个 `.tsv` 文件四列，用制表符分隔：

```
# 编号	汉字	假名	英文释义
3412	会う	あう	to meet
3413		あおい	blue; azure
```

**要做的事**：把第四列的英文释义翻成中文，输出两列——编号和中文，
其余什么都不要加：

```
3412	见面
3413	蓝色；青色
```

**几条要求**

- **编号必须原样照抄**，回填靠它对齐，错一个就串行。
- **一行一条，不要合并、不要漏行、不要改顺序**。行数必须跟原文件一样。
- 多个义项用中文分号「；」隔开，最多三个。
- 只给词义，不要加词性、例句、罗马音、注释。
- 拿不准的词，看汉字和假名帮助判断——日语汉字词的意思常跟中文相近，
  但也有「手紙＝信」这种假朋友，别照搬汉字。
- 英文释义本身可能有多个义项（用分号隔开），对应着翻，不要只翻第一个。

## 回填

翻好的内容存成 `<原文件名>.zh.tsv` 放在同一个目录，比如
`n5_01.tsv` 翻完存成 `n5_01.zh.tsv`。然后跑：

```
cd /home/ysc/mcp && .venv/bin/python kg/content/translate/merge.py
```

它会逐条核对编号、检查中文里没混着英文和日文假名，确认无误才写回
`words_jlpt.jsonl`，并报告哪些批次还没翻。

## 为什么要人工对一遍

机器翻译日语词义的坑在于一词多义和词性：`かける` 有二十多个意思，
`いい` 在不同语境是「好」也是「不用了」。这批词是拿来出题的，
释义错了题就是错的。
