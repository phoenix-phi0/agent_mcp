# ～さえ（N3，课文编号 hb-n3-021）

“连……都”；与ば连用表示“只要……就”

## 接续

名词 + さえ／でさえ；动词ます形 + さえ + すれば；动词て形 + さえ + いれば；い形容词く + さえ + あれば；な形容词で + さえ + あれば

## 讲解

有两种用法：①举出极端的例子，暗示其他的更不用说，“连……都”，常与否定搭配；②「～さえ～ば」表示“只要满足这一个条件就够了”。名词作主语时常用「でさえ」，如「先生でさえ」。动词要用「ます形 + さえ + すれば」「て形 + さえ + いれば」，不能直接接在普通形后。

## 例句

- お金さえあれば、世界中を旅行できる。
  只要有钱，就能周游世界。
- 彼は英語さえ話せれば、その仕事ができるだろう。
  他只要会说英语，就能干那份工作吧。
- この問題は難しすぎて、先生でさえ解けなかった。
  这道题太难了，连老师都没解出来。
- 忙しくて、昼ご飯を食べる時間さえなかった。
  忙得连吃午饭的时间都没有。
