# ～に対して（N3，课文编号 hb-n3-082）

表示对象“对……”，或对比“与……相反”

## 接续

名词 + に対して；动词／い形容词普通形 + のに対して；な形容词・名词 + な／である + のに対して

## 讲解

有两种用法：①表示动作、态度针对的对象，“对……”“针对……”，如「質問に対して答える」；②表示两者对比，“与……相反／相比”，前面接句子时要加「の」，即「普通形 + のに対して」。修饰名词用「～に対する + 名词」。

## 例句

- 子供たちに対して、親は常にやさしくあるべきです。
  父母对孩子应该始终温和。
- 彼は質問に対して正直に答えました。
  他如实回答了提问。
- 田中さんが成功したのに対して、佐藤さんは失敗しました。
  田中成功了，而佐藤却失败了。
- 彼の意見に対して、私は反対の立場を取りました。
  对于他的意见，我持反对立场。
